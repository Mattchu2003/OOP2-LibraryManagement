Library Management System

A simple terminal based Library Management System made using Java and Object-Oriented Programming principles.

Features

- Add books
- Display books
- Borrow books
- Return books

OOP Concepts Used

- Encapsulation
- Objects and Classes
- Constructors
- ArrayList
- Composition

Classes

- Main.java → Runs the program
- Library.java → Handles library operations
- Book.java → Represents books
- Member.java → Represents library users

How to Run

1. Open project in IntelliJ
2. Run Main.java
